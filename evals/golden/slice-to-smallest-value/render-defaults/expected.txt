# S1: Request a reset link

## Value
A locked-out user can get back to their notes

## Context
Tokens are stored in the existing sessions table; mail goes through src/mail/send.ts.

## Scope
- Reset request form
- Email with a one-time link

## Files
- `src/auth/reset.ts`
- `web/pages/reset.tsx`

## Acceptance criteria
- [ ] Submitting a known email sends one link
  - proof: tests/reset.test.ts::sends link

## Out of scope
- Link expiry
- Rate limiting

## Dependencies
- None

# S2: Expire reset links

## Value
An old reset email cannot be used to take over an account

## Scope
- Store issued-at on the token
- Reject tokens older than 60 minutes

## Files
- `src/auth/expiry.ts`

## Acceptance criteria
- [ ] A 61-minute-old link is rejected with a clear message
  - proof: test_expired_token

## Dependencies
- Depends on S1
- Depends on #40
- Depends on acme/api#7
